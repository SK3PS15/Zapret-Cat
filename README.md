## 🇬🇧 ENGLISH VERSION

**ZapCat** is a modern, user-friendly graphical user interface (GUI) for the **Zapret** DPI bypass utility. Built with HTML, CSS, JavaScript, and powered by a Python backend via `pywebview`, ZapCat brings a sleek winter-themed UI and an interactive mascot to make managing DPI strategies simple and enjoyable.

### ✨ Features

- 🐱 **Interactive Mascot:** Animated black cat mascot that reacts to connection states, blinks, and gets hearts in its eyes when the bypass is active.
- ⚡ **One-Click Control:** Easily start, stop, and toggle DPI bypass directly from the main screen.
- 🔍 **Automated Strategy Finder:** Built-in testing tool to help you scan and discover the most effective strategy for your ISP.
- ⚙️ **Flexible Configuration:** Quickly tweak game filters (TCP/UDP), IPSet parameters, domain lists (`list-general-user.txt`), and exclusion rules.
- 🛠️ **Maintenance Tools:** Access diagnostic logging, Discord cache cleaning, IPSet/hosts updates, and service management options in one place.
- ❄️ **Atmospheric UI:** Dark glassmorphism winter design with a snow falling effect and dual-language support (English & Russian).

### ⚠️ Troubleshooting: Fixing Connection / Service Issues

If the DPI bypass is not working properly, failing to start, or stuck in a loading state, follow these quick reset steps using the built-in UI:

1. Open **ZapCat**.
2. Navigate to the **Tools** tab (`Инструменты`).
3. Click **Update Services** (`Обновить службы`).
4. Click **Uninstall Services** (`Удалить службы`) at the bottom of the tools list.
5. Click **Install Service** (`Установить службу`) to perform a clean reinstall.

> **Why does this happen?**  
> Windows may hold onto cached or conflicting service entries from previous Zapret or GoodbyeDPI installations. Reinstalling the service through the Tools menu clears these stale system entries and registers a fresh instance.

## 🇷🇺 РУССКАЯ ВЕРСИЯ

**ZapCat** — это современный и удобный графический интерфейс (GUI) для утилиты обхода блокировок **Zapret**. Написан на HTML, CSS, JavaScript и работает на базе Python через `pywebview`. ### ✨ Основные возможности

- 🐱 **Интерактивный маскот:** Анимированный черный кот реагирует на статус подключения, моргает и показывает сердечки в глазах при включенном обходе.
- ⚡ **Управление в один клик:** Быстрый запуск, остановка и переключение обхода прямо с главного экрана.
- 🔍 **Автоматический поиск стратегий:** Встроенное тестирование подберет самую эффективную конфигурацию под вашего провайдера.
- ⚙️ **Гибкие настройки:** Удобное редактирование игровых фильтров (TCP/UDP), параметров IPSet, списков доменов (`list-general-user.txt`) и исключений.
- 🛠️ **Инструменты обслуживания:** Доступ к логам диагностики, очистке кеша Discord, обновлению IPSet/hosts и управлению службами в одном окне.

### ⚠️ Решение проблем: Сброс и переустановка службы

Если обход блокировок работает нестабильно, не запускается или «зависает» загрузка, выполните следующие шаги прямо из интерфейса:

1. Откройте **ZapCat**.
2. Перейдите во вкладку **Инструменты**.
3. Нажмите **Обновить службы**.
4. Нажмите **Удалить службы Zapret** в самом низу списка.
5. Нажмите **Установить службу** для чистой переустановки.

> **Почему это происходит?**  
> В системе Windows могут оставаться старые кэшированные или конфликтующие службы от прошлых установок Zapret или GoodbyeDPI. Переустановка службы через меню инструментов полностью очищает старые записи и регистрирует чистую службу.
